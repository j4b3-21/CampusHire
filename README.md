# CampusHire

Training & Placement CRM/ERP for colleges, built on **BM4A**, a metadata-driven multi-tenant platform.

Students, departments, companies, drives, applications, interviews and offers for four roles (TPO, department
coordinators, students, recruiters) with Excel/CSV everywhere, an eligibility engine, a configurable application
workflow, live analytics and Google sign-in for students.
